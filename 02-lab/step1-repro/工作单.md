## 三、必答问题

### Q1 哪些错了，错到哪去了

6 个仿真设定里有 3 个判错。写出：设定 → 误判结果 → 置信度。
然后在 `report.md` 第二节的表里，把"判错的那一行"和"被它误认成的那一行"逐列对比，指出哪几列数值几乎一样。

> 这一问训练的是：**不要只看结论，要回到特征空间找证据。**

### Q2 幅度这个特征还剩多少信息

`amplitude_rel` 在 nominal / R_too_high / R_too_low 里都在 0.94 附近。把摆幅从 1V 加到 8V，它怎么变？

- 一个特征对 1V 和 8V 都输出同一个数，它还能区分"这个电阻接错了"吗？
- 它实际上只保留了哪一类信息？（提示：有信号 / 无信号）

> 这一问训练的是：**特征饱和 = 信息丢失，而且不会报错，只会悄悄变哑。**

### Q3 为什么"没信号"的过零率最高

`no_oscillation` 的 zcr ≈ 5018 /s，`nominal` 只有 4.8 /s。采样率是 10000 Hz。

提示：纯白噪声相邻两个样本异号的概率是 0.5，所以每秒期望过零次数是 fs/2 = 5000。
再问自己：过零率的单位是什么？它是一个"次数/时间"的计量，**有没有考虑信号本身的幅度**？

> 这一问训练的是：**同一个名字的指标，在"有周期信号"和"只有底噪"两种工况下物理含义完全不同。**

### Q4 核心：为什么 7 Hz 的 555 被判成比较器

设定是 `R_too_low`（555 太快的波形），模型判成 `mode_C__nominal`（比较器正常）。

1. 模型的输入向量里有几位？分别是什么？里面有没有"我现在测的是哪个电路"？
2. 如果不给模式信息，那"7 Hz、amp 0.94、zcr 13.8、spread 328"这组数，在 13 个类里是不是只能有一个合法答案？
3. 那么这是模型训练得不好，还是**类别定义本身在特征空间里重叠**？

> 这一问训练的是：**先问"信息够不够"，再问"模型好不好"。调参救不了信息缺失。**

## 四、一个小实验：把模型的"决策地图"画出来

`probe.py` 不碰只读副本，自己在本地造方波喂给模型：

```
python probe.py 5          # 5 Hz 方波
python probe.py 5 0.6      # 5 Hz，占空比 60%
```

**实验 A（横轴：频率）** 依次跑 `0.5 1 2 3 5 10 20 50 100 200`，填这张表：

| 频率 Hz | 0.5 | 1 | 2 | 3 | 5 | 10 | 20 | 50 | 100 | 200 |
|---|---|---|---|---|---|---|---|---|---|---|
| 判成 | | | | | | | | | | |

看两个问题：**整段 0.5–200 Hz 里，`mode_A` 出现过几次？** 大片频段是不是塌进了同一个类？

**实验 B（横轴：占空比）** 固定 `5 Hz`，把占空比依次改成 `0.2 0.4 0.6 0.8 0.95` 再填一张表；
然后把频率换成 `2.5` 重复一遍（这一档才是关键）。

做完把两张表叠起来看，你会得到两个观察：

1. 大片频段整段塌进同一个类，`mode_A` 只在很窄的角落里露过脸；
2. 频率和占空比**都会**把判定推来推去，但方向不一致——说明它抓的是"频率 + 边沿密度"这类间接量，
   而不是"这是哪个电路"。5 个特征里既没有模式，也没有占空比。

这就是 Q4 的实证版：不是模型"认错"，是它手里根本没有能分开这两个模式的变量。

## 五、300 字怎么写

骨架（按这个顺序写，不要分点，写成一段话）：

1. 我复现了什么，6 个里错 3 个；
2. 举两个最典型的错，带数字；
3. 三个机制各一句：**幅度特征饱和**、**过零率在底噪下物理含义反转**、**5 个特征里没有模式信息导致类间不可分**；
4. 一句结论：这类"AI+信号"的工作，瓶颈不在模型，在特征是否携带了能分开类别的物理量；
5. 一句下一步：我会重写特征，并把"同一段录音切出来的样本"放进同一折交叉验证，避免再出现 100% 这种自证准确率。

**别写成**："这个项目做得很差 / 作者水平不行"。写机制，不写评价——这是你和"网上看热闹的人"的区别，也是回访老师时唯一值钱的部分。
