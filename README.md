# 从「AI 示波器」到可解释的电路故障诊断

一次「AI + 信号分析」方向的入门尝试：复现一个 hackathon 项目，**发现它的判定并不来自波形本身的信息**，于是重写特征、按电路物理生成数据、按批次验证，并写了一个可以演示的统一入口。

原始项目：[tanishmisra9/scopeai](https://github.com/tanishmisra9/scopeai)（Purdue Catapult Hacks 2026）。本仓库只借用它的思路与对照基线，**不包含它的任何源码**。

## 结果

三个电路模式、13 个工况，按"批次"分组交叉验证（同一批次的样本不跨训练/测试）：

| 模式 | 类别数 | 多数类基线 | 本方法 | 原版 5 特征 |
|---|---|---|---|---|
| A（NE555 方波） | 5 | 20% | **100%** | 76.7% |
| B（RC 充放电） | 4 | 25% | **97.9%** | 70.8% |
| C（比较器） | 4 | 25% | **100%** | 81.2% |

逐工况演示 13 个判对 12 个；没判对的那个在 `02-lab/step4-app/demo.md` 里带着原因保留。

同一份数据上的输入表示消融：

| 输入 | 模型 | 准确率 |
|---|---|---|
| 11 个物理特征 | RandomForest | **96.2%** |
| 时频图 64×64 | 小型 2D CNN | 75.6% |
| 原始波形 2048 点 | 小型 1D CNN | 51.0% |

## 三个关键发现

1. **幅度特征被截断**：原实现 `clip(ptp/2, 0, 1)`，摆幅超过 2 V 就恒等于 1.0，真实 0–5 V 电路上等于一个常数。
2. **过零率在底噪下含义反转**：白噪声的期望过零率是采样率的一半（约 5000/s），而训练期望是 0.1/s——差四个数量级，于是"电路死了"被判成"变化最快"。
3. **输入里没有模式信息**：13 个类别按"模式 × 故障"划分，而模型只吃 5 个特征，7 Hz 的 555 输出与"比较器正常"在特征空间里重合。

## 快速开始

需要 Python 3.10+，以及 `numpy scipy scikit-learn joblib`；消融实验额外需要 `torch`（CPU 即可）。

```bash
# 1) 复现原项目的三个错判（需要先把原项目 clone 到 01-readings/scopeai）
python 02-lab/step1-repro/repro.py

# 2) 特征对照
python 02-lab/step2-features/compare.py

# 3) 训练三个模型（约 1 分钟）
python 02-lab/step3-models/train.py

# 4) 演示：给定模式与工况
python 02-lab/step4-app/cli.py --mode A --fault R_too_high
python 02-lab/step4-app/demo.py        # 13 个工况一次跑完
```

> 第 1 步依赖原项目副本：`git clone https://github.com/tanishmisra9/scopeai 01-readings/scopeai`。
> 其余步骤都不需要它。

## 设计取舍

- **模式由操作者给定，不由模型猜。** 牺牲"自动识别电路"，换取判定可靠——因为"测的是哪个电路"本来就不是波形里必然存在的信息。
- **大模型不进入判定链路。** 原项目的 GPT-4o 只负责把这几个数转成一句话，它拿到的是判定结果本身，没有纠错能力。
- **只用分组交叉验证说话。** 随机切分会让同一批次的增益、噪声泄漏到测试集，准确率虚高。

## 局限

全部为仿真；真实电路的探头衰减、地环路噪声、采样抖动尚未进入；正常区间绑死在假定的元件参数上，换板需要重新标定；每类仅 48 段，方差仍然可观。

## Roadmap

- [ ] **接入大模型「对话式追问」**（只做解释与问答，判定不变）
  - 上下文：`latest_context.json`——模式、判定、置信度、前三名、11 个特征、正常区间、允许引用的元件值
  - 约束：判定结果只读；数值只准引用上下文，不许自己算；看不到波形，超出范围就明说
  - 降级：无 key / 断网 / 超时 → 回落到规则文本，并提示"已切换到离线解释"
  - 验收：10 道题（结果类 / 操作类 / 原理类），人工判"是否编数值 / 是否改判定 / 建议是否可执行"
- [ ] **适配真实数据**：声卡或 STM32 采集、健康状态标定、以"相对基线"代替绝对阈值、用留一次装配的方式评估。
- [ ] 批次数从 6 提到 10–12，观察 Mode B 剩余误差是否收敛。
- [ ] 在更大样本量上重做输入表示消融，确认"手写特征更省数据"的边界。
